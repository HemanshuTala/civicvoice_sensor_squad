# Civic Voice



# Introduction

Civic Voice is an innovative platform developed during a hackathon to empower citizens by providing a seamless way to voice their concerns and suggestions regarding public services and infrastructure. This project aims to bridge the gap between the community and local authorities, fostering transparency and engagement.

# Features

User-Friendly Interface: Simple and intuitive design for easy navigation.

Issue Reporting: Citizens can report issues related to roads, sanitation, public transport, and more.

Real-Time Tracking: Users can track the status of their reported issues.

Community Engagement: Allows citizens to upvote and comment on reported concerns.

Admin Dashboard: For local authorities to monitor, categorize, and resolve complaints efficiently.

Hierarchical Admin System:

Admin (District Level Admin): Manages district-level issues.

Super Admin (State Level Admin): Oversees all district-level admins, monitors their activities, and can modify deadlines for reported issues.

# Technologies Used

Frontend: React.js

Backend: Node.js, Express.js

Database: MongoDB

Authentication: JWT-based authentication

# Installation & Setup

Clone the repository:
```sh
[git clone https://github.com/HemanshuTala/civicvoice_sensor_squad.git]
```
Navigate to the project directory:
```sh
cd civicvoice_sensor_squad
```

Install dependencies:
```sh
npm install
```
Set up environment variables:

Create a .env file and add required configurations (e.g., database URL, API keys).

Start the development server:
```sh
npm run dev
```
# Usage

Sign up or log in.

Report an issue by providing details and optionally uploading images.

View and interact with community-reported issues.

Admins can log in to manage and resolve reports.

Super Admin can monitor all activities of district-level admins and modify deadlines.
